# Operating-System-Algorithms

**1.Page Replacement Algorithms Simulator**

This project is an interactive Operating System simulator designed to demonstrate how different page replacement algorithms work in memory management. The simulator allows users to enter custom reference strings, set frame sizes, and compare the performance of multiple algorithms based on page faults and hit rates. It helps students understand the practical implementation and behavior of memory management techniques through visualization and real-time analysis.

**Algorithms Implemented:-**
-FIFO (First In First Out)
-LRU (Least Recently Used)
-Optimal Page Replacement

**Tech Stack** - Python, Streamlit, Plotly, Pandas

**Features:-**
-Custom page reference string input
-Adjustable frame size
-Real-time page fault tracking
-Graphical comparison of algorithms
-Interactive and user-friendly interface
-Performance visualization using charts


**2.CPU Scheduling Algorithm Simulator**

This project is an interactive simulator that demonstrates the working of different CPU scheduling algorithms used in Operating Systems. The simulator helps users visualize process execution, scheduling order, waiting time, turnaround time, and CPU utilization through graphs and Gantt charts. It is designed as an educational tool for learning process scheduling concepts in a practical and interactive way.

**Algorithms Implemented:-**
-First Come First Serve (FCFS)
-Shortest Job First (SJF)
-Shortest Remaining Time First (SRTF)
-Largest Job First (LJF)
-Largest Remaining Time First (LRTF)
-Round Robin (RR)
-Priority Scheduling (Preemptive)
-Highest Response Ratio Next (HRRN)

**Tech Stack** - Python, Streamlit, Plotly, Pandas

**Features:-**
-Gantt Chart visualization
-Waiting time calculation
-Turnaround time calculation
-Average performance metrics
-Interactive process input system
-Graphical performance comparison
